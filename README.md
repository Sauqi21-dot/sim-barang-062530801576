## Konsep HTTP Request dan Response
HTTP adalah aturan komunikasi antara client (browser) dan server.

- **Request**: browser meminta sesuatu ke server, berisi method (GET/POST),
  alamat URL, header, dan kadang data (misalnya isi form).
- **Response**: server membalas dengan status code (200 = berhasil,
  404 = tidak ditemukan, 500 = error server), header, dan isi halaman.

Contoh alur: user membuka `localhost/sim-barang` -> browser mengirim
request GET -> Apache memproses -> server mengirim response berupa halaman HTML.
